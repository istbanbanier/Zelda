# RECHERCHE ASSETS — NORTH STAR FPS V0

Date de recherche : 2026-08-30  
Projet : Éclats d'Orage / World V2  
Référence de base inspectée : `8c6955c6277e371327c71079bacaa6a8c2e44fac`

## Décision en une phrase

Le dépôt n'a pas besoin d'un nouveau déversement de packs low-poly génériques. Il
possède déjà une base CC0 considérable et bien documentée. Pour rejoindre la
North Star FPS choisie par Istvan, il faut désormais **promouvoir et harmoniser
l'existant**, puis combler seulement quatre manques à forte visibilité : forêt de
premier plan, pierre/ruines de premier plan, rig de mains/Bracelet en première
personne et quelques personnages/boss héroïques.

## 1. Ce qui est déjà présent et doit être utilisé avant tout achat

Le dépôt contient et attribue déjà :

- Quaternius CC0 : Stylized Nature MegaKit, Fantasy Props MegaKit, Medieval
  Village MegaKit, Universal Base Characters, Modular Character Outfits –
  Fantasy, Universal Animation Library 1 et 2 ;
- ambientCG CC0 : roche, sol, herbe, écorce et tissu en PBR ;
- Kenney CC0 : Nature Kit, Castle Kit, Modular Cave Kit, Fantasy Town Kit,
  Graveyard Kit, Survival Kit, Watercraft Kit, VFX et audio ;
- KayKit Dungeon Pack CC0 ;
- créations propres du projet : épée usée, trois pillards, troll, chasseur et
  Gardien de l'Orage ;
- une bibliothèque de quarantaine sous `asset_library/inbox/`, protégée par
  `.gdignore`, dont les candidats ne doivent entrer dans `assets/` qu'après
  sélection et preuve.

Autorités internes à lire avant toute promotion :

- `ATTRIBUTIONS.md` ;
- `asset_library/README.md` ;
- `asset_library/SOURCES.lock.csv` ;
- `docs/assets/ASSET_MANIFEST.csv` ;
- `docs/assets/PROMOTIONS.csv` ;
- `docs/assets/IMPORT_RULES.md`.

Conclusion : les éléments secondaires, lointains et répétitifs doivent venir de
cette base existante. Un nouveau pack n'est justifié que s'il élève un plan de
premier plan que l'existant ne peut pas atteindre après harmonisation.

## 2. Direction artistique verrouillée

La cible est une première personne painterly/semi-réaliste :

- deux mains présentes, Bracelet de Résonance turquoise à gauche, arme à droite ;
- grandes vues lisibles avec routes, eau, tours et front d'orage ;
- densité végétale près des foyers, respiration ailleurs ;
- roches stratifiées et ruines patinées ;
- contraste froid turquoise de l'orage / chaud ambre des foyers humains ;
- ennemis lisibles par silhouette et télégraphe, pas par surbrillance UI ;
- aucun mélange visible de low-poly plat, PBR réaliste brut et cartoon mobile.

La North Star est une intention, jamais une texture, une skybox, un billboard ou
une fausse capture de jeu.

## 4. Première personne : fabriquer plutôt qu'acheter à l'aveugle

Le meilleur chemin actuel est un rig de vue original construit à partir de ce que
le projet possède déjà :

1. dupliquer hors build un personnage Quaternius CC0 compatible avec le squelette
   existant ;
2. garder seulement épaules/avant-bras/mains utiles à la caméra ;
3. remodeler manchettes, cuir et proportions pour le plan rapproché ;
4. construire le Bracelet comme hero prop original autour de l'avant-bras gauche ;
5. conserver `SM_WornSword` à droite pour le premier pilote ;
6. produire en Blender les animations spécifiques : idle respiré, marche, sprint,
   saut, blocage, trois attaques, interaction Bracelet, impact et récupération ;
7. exporter en GLB via la chaîne déjà contractuelle ;
8. vérifier clipping caméra, FOV, ombres, animation, sockets, latence d'attaque et
   lisibilité de l'UI.

Mixamo peut accélérer les corps humanoïdes et les animations générales : Adobe
autorise personnages et animations dans les jeux commerciaux. Mais son auto-rig
est limité aux bipèdes humanoïdes et ses animations plein corps ne remplacent pas
un vrai jeu d'animations première personne. Quaternius Universal Animation Library
reste le premier choix gratuit déjà compatible avec le dépôt.

## 5. Licences et dépôt Git

### Approuvé sans achat

- Quaternius, Kenney, ambientCG et Poly Haven : CC0 selon leurs pages officielles.
- Les assets déjà entrés dans le build restent soumis au manifeste interne.

### Fab

La Fab Standard License autorise l'usage commercial, la modification, l'usage
avec des outils compatibles autres qu'Unreal et le partage avec les
collaborateurs du projet. Elle interdit de redistribuer l'asset seul. Par
conséquent :

- aucun pack complet ne doit être ajouté à ce dépôt public ;
- seuls des dérivés ou sélections nécessaires au projet peuvent être versionnés,
  si la licence exacte choisie le permet et si les sources brutes ne sont pas
  exposées comme une bibliothèque autonome ;
- les archives d'achat restent hors Git ;
- chaque promotion reçoit auteur, URL, licence, modifications et SHA-256 dans
  `ATTRIBUTIONS.md` et `docs/assets/ASSET_MANIFEST.csv`.

### Interdiction de l'option « Reference-Only »

Cette option ne donne pas les formats sources. Elle ne convient pas à une chaîne
Blender → GLB → Godot et doit être rejetée.

## 6. Pipeline d'acquisition imposé

Pour chaque source externe nouvelle :

1. vérifier l'URL officielle, l'auteur, le prix du jour et la licence exacte ;
2. confirmer qu'un format neutre existe : GLB/glTF de préférence, sinon FBX ou
   Blend ;
3. télécharger l'archive dans une quarantaine ignorée par Godot et Git ;
4. conserver licence, facture/preuve d'acquisition et SHA-256 ;
5. inventorier textures, triangles, LOD, rigs, animations, pivots et collisions ;
6. sélectionner le minimum utile ;
7. normaliser dans Blender ;
8. exporter GLB et passer `tools/gltf_inspect.py` ;
9. importer dans une scène laboratoire Godot ;
10. rendre A/B/C depuis la caméra joueur réelle ;
11. n'autoriser la promotion vers `assets/` qu'après PASS visuel et technique ;
12. inscrire la promotion dans les deux manifestes avant le commit.

## 7. Pilotes à produire dans l'ordre

1. **Vue FPS** : bras gauche + Bracelet + épée existante, sans toucher aux POI.
2. **Forêt laboratoire** : existant Quaternius vs A1 vs A2, même lumière et même
   caméra.
3. **Ruine laboratoire** : Kenney/KayKit vs A3, même composition.
4. **Source laboratoire** : végétation existante vs B1, seulement si le gain est
   visible à taille réelle.
5. **Ennemi laboratoire** : pillard actuel vs échantillon B3, hors Lot 2.

Chaque pilote doit répondre à une seule question visuelle. S'il n'améliore pas
clairement la North Star en rendu Godot, il est rejeté même s'il est techniquement
propre.

## 8. Budget et anti-bloat

- aucune archive marketplace dans Git ;
- aucun pack entier dans `assets/` ;
- textures de production : 1K par défaut, 2K seulement pour hero/foreground avec
  justification ;
- variantes par shader, vertex color ou atlas avant duplication de textures ;
- MultiMesh/LOD/impostor pour la végétation répétée ;
- le dépôt fait déjà environ 2,4 Go : chaque ajout doit annoncer poids brut,
  poids promu et poids exporté ;
- pas plus d'un candidat payant par famille dans le premier comparatif.
